- **Routing Layer**: Uses `@tanstack/react-router` file-based routing (`studio_.courses.tsx`, `studio_.courses.new.tsx`, `studio_.courses.$courseId.edit.tsx`) to map URL patterns to the unified `CourseStudioPage` component, passing specific `courseId` props (`null`, `'new'`, or dynamic ID).
- **Page Composition**: `CourseStudioPage` acts as a conditional renderer, delegating to `CourseList` (dashboard), `NewCoursePage` (creation form), or `CourseEditor` (complex editing workspace) based on the `courseId` prop.
- **Feature Components**: `CourseEditor` implements a two-column layout with a structural tree (modules/lessons) and a detailed `LessonEditor` (Markdown content, attachments), while `NewCoursePage` handles initial metadata capture.
- **Data Integration**: Relies on `@tanstack/react-query` for server state management, utilizing custom hooks from `../lib/courses` for CRUD operations on courses, modules, lessons, and attachments, with optimistic UI updates via `queryClient.invalidateQueries`.
